# 💳 Credit Card Fraud Detection using Machine Learning

## 📌 Overview
This project focuses on detecting fraudulent credit card transactions using Machine Learning techniques. Since fraud cases are rare, the dataset is highly imbalanced. To handle this, SMOTE (Synthetic Minority Oversampling Technique) is applied to improve model performance.

---

## 🎯 Objective
- Identify fraudulent transactions accurately
- Handle imbalanced dataset effectively
- Build a reliable classification model
- Evaluate performance using appropriate metrics

---

## 📊 Dataset
- Source: Kaggle Credit Card Fraud Dataset
- Contains anonymized transaction data
- Highly imbalanced (fraud cases are very low)

---

## ⚙️ Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Imbalanced-learn (SMOTE)
- Matplotlib, Seaborn

---

## 🧠 Machine Learning Workflow
1. Data Loading & Exploration  
2. Data Preprocessing  
3. Train-Test Split  
4. Handling Imbalance using SMOTE  
5. Model Training (Logistic Regression)  
6. Model Evaluation  

---

## 🤖 Model Used
- Logistic Regression

---

## 📈 Evaluation Metrics
- Precision  
- Recall  
- F1-score  
- Confusion Matrix  

---

## 📊 Results
- Improved detection of fraud cases using SMOTE
- Model performs well in identifying minority class (fraud)
- Confusion matrix shows effective classification

---

## 🔧 Improvements
- Applied StandardScaler for better model convergence
- Increased max_iter for improved performance

---

## 🔍 Key Insights
- Dataset is highly imbalanced  
- SMOTE helps balance training data  
- Recall is critical to reduce missed fraud cases  
- Logistic Regression performs effectively  

---

## 🚀 Conclusion
The model successfully detects fraudulent transactions by addressing class imbalance. This approach can be used in real-world financial systems to minimize fraud risk.
